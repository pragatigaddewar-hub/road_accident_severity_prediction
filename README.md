# Road Accident Severity Prediction

## Project Overview

This project uses machine learning classification algorithms to predict road accident severity based on road, traffic, driver, weather, and lighting conditions.

## Dataset

The dataset contains information about road accidents and their related conditions.

## Target Variable

**Accident_Severity**

* Low
* Moderate
* High

## Machine Learning Models

* Logistic Regression
* K-Nearest Neighbors (KNN)
* Decision Tree
* Random Forest
* Support Vector Machine (SVM)
* Naive Bayes

## Project Workflow

Data Collection → Data Understanding → Data Cleaning → Exploratory Data Analysis → Feature Selection → Encoding → Train-Test Split → Scaling → Model Building → Model Evaluation → Model Comparison → Final Model → Unseen Data Prediction

## Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Final Prediction

The selected final model was trained on the complete cleaned dataset and used to predict accident severity for unseen data.
